    03

    Before it goes live

    What the kitchen would confirm so every pick is right.

    Spice levels for all dishes

    Every level here is our estimate of the dish as usually made. The planner never picks above the chosen line; where a course has nothing that gentle, it picks the mildest and says “ask for it milder”.

    Diet marks, especially hidden egg

    Naan dough, Indo-Chinese batters and a few desserts can contain egg. We need the kitchen’s word before the “Veg only” filter can promise egg-free.

    Four dishes we left out

    Lamb Seekh Kabab, Lamb Chop Kabab, Bullet Naan and Paratha appear only on older or uncertain listings, so the planner never shows them.

    Portions and weekend-only dishes

    Quantities use simple rules (about one bread per person, one curry per two guests). Real portion sizes would tune them. Goat Dum Biryani carries a “Weekends only” badge until confirmed.

    The phone number

    (469) 200-5856 is the likely main line from public listings. It is set in one place, so it’s a one-line change once the owners confirm.
