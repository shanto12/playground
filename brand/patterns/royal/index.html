    Using them

    Good to know

    On the web

    Use the SVG as a CSS background: background: url(04-marigold-damask-midnight.svg) 0 0 / 320px repeat; Keep text on a solid panel above busy repeats.

    In print

    SVGs are vector and scale to any wall. For tissue and napkins choose Brass Dots, Spice Botanical or Paisley Vine at a larger scale; fine hairlines stay crisp from about a 10 cm repeat up.

    Palette

    Only Royal tokens: midnight #160B26, plum #4B1D52, emerald #0F4D3F, peacock #117C86, ruby #A3173F, ivory #FBF3E4, blush #F4C9BB and the three golds.
