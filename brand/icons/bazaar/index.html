One colour, any colour it's all currentColor

The mono twins draw with currentColor, so a single CSS color rule re-skins them for any background — same shapes, same 3px line.

How to use copy, paste, eat

<!-- 1 · single file (colour) -->
<img src="icons/bazaar/naan.svg" width="32" height="32" alt="Naan">

<!-- 2 · sprite: inline sprite.svg once, then reference by id -->
<svg class="icon" aria-hidden="true"><use href="#icon-chili-3"/></svg>Hot

<!-- 3 · mono twin, coloured by CSS -->
<svg class="icon" style="color:var(--bz-rani)"><use href="#icon-heart-mono"/></svg>

/* sizing */
.icon { width: 32px; height: 32px; flex: none; }
  • Ids: icon-<name> is colour, icon-<name>-mono is the currentColor twin. Files: <name>.svg and mono/<name>.svg.
  • Smallest size: 24px. Below that the 3px line gets thinner than a pixel — use the mono twin at 20px if you must.
  • Accessibility: icons next to a text label get aria-hidden="true"; a lone icon button needs an aria-label. Diet and spice marks always travel with words.
  • External sprite (<use href="sprite.svg#…">) works over http(s) on the same origin, not from file:// — inline it for local previews.
