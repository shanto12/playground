Six hero dishes, plated in gold

Hand-built vector plates: soft gradients, saffron-gold hairlines and candlelit gloss. Transparent 800×800 SVGs made to float on midnight, emerald or ivory. Steam and glints are live layers you can animate (.steam, .glint).

Using the files

  • Each SVG is self-contained: no raster, no text, no external references. Every ID is prefixed per dish (bc-, br-, td-, gn-, sm-, pt-), so all six can be inlined on one page.
  • Inline the SVG to animate it: target .steam path (drift up and fade) and .glint > * (scale and opacity twinkle). Use transform-box: fill-box, animate only transform and opacity, and switch it off under prefers-reduced-motion.
  • Steam is white and soft, so it shows best on midnight and emerald. On ivory it almost disappears, which is intended.
  • The png/ folder holds transparent 800px renders for social posts and listings.
