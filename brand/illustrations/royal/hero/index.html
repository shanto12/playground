Arch-frame mask

Any dish photo, framed like a palace window

Same cusped profile as the hero arches. Use the SVG mask, the pure-CSS polygon, or the inline clipPath in arch-frame.css.

/* arch-frame.css — drop any image into an arch window */
.cd-arch { aspect-ratio: 400 / 645; overflow: hidden;
  -webkit-mask: url(arch-frame.svg) center / 100% 100% no-repeat;
          mask: url(arch-frame.svg) center / 100% 100% no-repeat; }
.cd-arch > img { width: 100%; height: 100%; object-fit: cover; }

/* no extra file? use the generated polygon instead */
.cd-arch--clip { clip-path: polygon( … see arch-frame.css … ); }
