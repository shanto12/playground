Notes for builders

  • Format: 800×800 viewBox, transparent background, no raster, text or external references; each file under 60 KB. PNGs in png/ are 800 px with alpha.
  • Animation hooks: every file has one <g class="steam"> (a soft haze layer plus crisp wisps) and one <g class="glint"> (glow + four-point sparkle pairs). Animate transform/opacity only; the CSS on this page is a drop-in starting point and respects reduced motion.
  • Safe to inline together: all ids are prefixed per dish (cc-, th-, ds-, gj-, ml-, ch-), so several plates can share one page without gradient clashes.
  • Matches set 1: same palette, foil gradient, steam and glint treatment, ground-shadow style and framing (dish centred around y ≈ 365, ground line ≤ 690), so both sets mix in one grid or carousel.
  • Steam on light grounds: wisps are white with a faint lavender haze, so they read clearly on midnight and emerald and quietly on ivory.
