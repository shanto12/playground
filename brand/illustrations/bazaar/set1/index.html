Wiring the motion

Every file ships with one <g class="steam"> (three round-capped wisps at 60% opacity) and nine <g class="sparkle"> groups. Neither carries a transform, so CSS transforms animate them cleanly once the SVG is inlined.

  • IDs are prefixed per dish (bc- by- tp- gn- sc- pt-), so all six can be inlined on one page.
  • Steam is ink by default; flip it to cream on dark surfaces.
/* inline the SVG, then: */
.steam path { animation: rise 3.2s ease-out infinite;
  transform-box: fill-box; transform-origin: 50% 100%; }
.steam path:nth-child(2) { animation-delay: -1.1s; }
.steam path:nth-child(3) { animation-delay: -2.2s; }
.sparkle { animation: twinkle 2.6s ease-in-out infinite;
  transform-box: fill-box; transform-origin: center; }
@keyframes rise { 0% { opacity: 0; transform: translateY(14px) scaleY(.85); }
  30% { opacity: 1; } 100% { opacity: 0; transform: translateY(-22px) scaleY(1.08); } }
@keyframes twinkle { 50% { transform: scale(.55) rotate(25deg); } }
/* on dark backgrounds */
.on-dark .steam { stroke: #FFF4DC; }
@media (prefers-reduced-motion: reduce) { .steam path, .sparkle { animation: none; } }
