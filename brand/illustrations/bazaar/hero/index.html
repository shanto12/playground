The same inline hero at real viewport widths. Under 700 px (or any tall screen) it swaps to the portrait re-composition: storefront bigger, sky kept clear for a headline.

Wiring it up

<!-- 1 · Inline the SVG markup (hero-portrait.svg under ~700px) -->
<div class="hero">…contents of hero-landscape.svg…</div>

<script>
/* 2 · Parallax: nudge each layer group by its own speed */
const speed = { sky:.26, sun:.34, clouds:.22, 'far-buildings':.16,
  'mid-buildings':.09, storefront:.09, people:.09, cart:.09,
  steam:.09, bunting:.07, lanterns:.09, foreground:0 };
const svg = document.querySelector('.hero svg');
addEventListener('scroll', () => requestAnimationFrame(() => {
  const r = svg.getBoundingClientRect();
  const p = Math.min(1, Math.max(0, -r.top / r.height));
  for (const id in speed) svg.querySelector('#' + id).style.transform =
    'translate(0px,' + p * speed[id] * svg.viewBox.baseVal.height + 'px)';
}), { passive: true });

/* 3 · Motion: loops live in the SVG's own <style> */
svg.classList.add('is-paused');   // pause every loop
// prefers-reduced-motion: reduce → loops are off automatically
</script>
Layer groups (exact ids)
#sky #sun #clouds #far-buildings #mid-buildings #storefront #people #cart #steam #bunting #lanterns #foreground
Animated classes
.cloud drift · .flag flutter · .lantern sway · .steam rise · .sun-rays rotate · .sun-glow pulse. Transform/opacity only.
Motion safety
Loops stop under prefers-reduced-motion. Add .is-paused to the <svg> for a pause button. The -static.svg files carry no animation at all.
Style
Flat vector, 3 px indigo outlines (portrait drawn heavier so it holds at phone size), hard offset shadows only under awnings, signs, balconies and the cart. No text, no marks, no religious symbols.
